About this snapshot

This page is a frozen static export of one run of the platform — real numbers, computed once, not a live dashboard. The full system (FastAPI + Streamlit, recomputable on demand) lives in the repo and runs locally against a synthetic 12-month DuckDB dataset. Clustering ground truth, change-failure ground truth, and every eval number here were checked against held-out labels the algorithms never saw — three real bugs were caught and fixed this way (a purity formula, a leaked label in the RAG eval, and a noise-driven capacity forecast) and are documented in the README with the fix.
